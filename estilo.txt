4. ATRIBUTOS Y ENCAPSULAMIENTO
==================================================

Los atributos representan las características de los objetos.

Ejemplo:

private int codigo;
private String nombre;
private double sueldoBase;
private int horasExtras;

TIPOS DE DATOS:

int:
Para cantidades, códigos numéricos, edades y créditos.

double:
Para precios, promedios, sueldos y presupuestos.

String:
Para nombres, descripciones, identificadores y fechas ingresadas como texto.

boolean:
Para representar estados verdaderos o falsos.

PRIVATE:

Permite restringir el acceso directo a los atributos.

PUBLIC:

Permite acceder a constructores y métodos desde otras clases.

IMPORTANTE:

El profesor ha trabajado tanto con atributos public como private.

En ejercicios iniciales se utilizaron atributos públicos.

En ejercicios posteriores se incorporó encapsulamiento mediante atributos privados y métodos get y set.

No imponer siempre private si el ejercicio utiliza otra estructura.

==================================================
5. CONSTRUCTORES
==================================================

El constructor permite inicializar los atributos cuando se crea un objeto.

Tiene el mismo nombre que la clase.

No tiene tipo de retorno.

Puede recibir parámetros.

Ejemplo:

public Empleado(int codigo, String nombre,
        double sueldoBase, int horasExtras) {

    this.codigo = codigo;
    this.nombre = nombre;
    this.sueldoBase = sueldoBase;
    this.horasExtras = horasExtras;
}

JUSTIFICACIÓN:

Se utiliza el constructor para asignar los valores iniciales de los atributos al momento de crear un objeto. Se implementa recibiendo los datos mediante parámetros y asignándolos a los atributos correspondientes.

ERROR QUE DEBE EVITARSE:

public void Empleado(...)

Eso no es un constructor porque contiene void.

==================================================
6. MÉTODOS GET Y SET
==================================================

GET:

Permite consultar el valor de un atributo privado.

Ejemplo:

public String getNombre() {
    return nombre;
}

JUSTIFICACIÓN:

Se utiliza para obtener información almacenada en un objeto sin acceder directamente a sus atributos privados.

PREFERENCIA DEL PROFESOR:

Dentro del getter se utiliza:

return nombre;

No es necesario escribir:

return this.nombre;

SET:

Permite modificar un atributo.

Ejemplo:

public void setNombre(String nombre) {
    this.nombre = nombre;
}

JUSTIFICACIÓN:

Se utiliza para actualizar el valor de un atributo. Se implementa mediante un parámetro que recibe el nuevo valor y lo asigna al atributo.

USO DE THIS:

Se utiliza especialmente cuando el parámetro y el atributo tienen el mismo nombre.

Ejemplo:

this.nombre = nombre;

No crear setters innecesarios cuando un atributo no debe modificarse.

==================================================
7. MÉTODOS VOID Y MÉTODOS CON RETORNO
==================================================

VOID:

Se utiliza cuando el método ejecuta una operación sin devolver un resultado.

Ejemplo:

public void mostrarDatos() {
    System.out.println("Nombre: " + nombre);
}

MÉTODOS CON RETORNO:

Se utilizan cuando una operación debe devolver un valor.

Ejemplo:

public double calcularPagoExtras() {
    return horasExtras * 20;
}

MÉTODOS QUE LLAMAN A OTROS MÉTODOS:

Ejemplo:

public double calcularSueldoTotal() {
    return sueldoBase + calcularPagoExtras();
}

JUSTIFICACIÓN:

Se utilizan para separar las operaciones, reutilizar cálculos y evitar repetir instrucciones.

==================================================
10. ESTRUCTURAS REPETITIVAS
==================================================

FOR:

Se utiliza para repetir instrucciones o recorrer colecciones.

Ejemplo:

for (int i = 0; i < productos.size(); i++) {
    productos.get(i).mostrarDatos();
}

JUSTIFICACIÓN:

Se utiliza para recorrer una colección mediante sus posiciones y ejecutar una operación sobre cada elemento.

FOR-EACH:

Ejemplo:

for (Producto p : productos) {
    p.mostrarDatos();
}

Se utiliza cuando solamente necesitamos recorrer los objetos sin trabajar directamente con sus índices.

Preferir el tipo de recorrido utilizado en los ejemplos del profesor o solicitado en el ejercicio.

11. ARRAYLIST
==================================================

ArrayList permite almacenar varios objetos de una misma clase.

Ejemplo:

ArrayList<Curso> cursos = new ArrayList<>();

Agregar:

cursos.add(c1);
cursos.add(c2);

Recorrer:

for (Curso c : cursos) {
    c.mostrarDatos();
}

JUSTIFICACIÓN:

Se utiliza ArrayList para almacenar una cantidad variable de objetos y facilitar su recorrido.

APLICACIÓN:

En el ejercicio de matrícula, una matrícula puede contener varios cursos.

No crear una matrícula diferente por cada curso cuando el alumno debe tener todos sus cursos en una misma matrícula.

17. RELACIONES UML
==================================================

ASOCIACIÓN:

Representa una relación entre objetos.

Ejemplo:

Alumno "1" -- "0..*" Matricula : tiene

HERENCIA:

Representa una relación entre una clase padre y una clase hija.

Ejemplo:

Persona <|-- Instructor

En Java:

public class Instructor extends Persona {
}

AGREGACIÓN:

Representa una relación donde los objetos relacionados pueden existir independientemente.

Ejemplo:

Equipo "1" o-- "0..*" Jugador : agrupa

COMPOSICIÓN:

Representa una relación fuerte donde el ciclo de vida de las partes depende del objeto contenedor.

Ejemplo:

Pedido "1" *-- "1..*" DetallePedido : contiene

DEPENDENCIA:

Representa una clase que utiliza otra.

Ejemplo:

TestProducto ..> Producto : utiliza

No inventar relaciones que no correspondan al programa.

ARCHIVO: Empleado.java

package ejercicio;

public class Empleado {

    private int codigo;
    private String nombre;
    private double sueldoBase;
    private int horasExtras;

    public Empleado(int codigo, String nombre,
            double sueldoBase, int horasExtras) {

        this.codigo = codigo;
        this.nombre = nombre;
        this.sueldoBase = sueldoBase;
        this.horasExtras = horasExtras;
    }

    public int getCodigo() {
        return codigo;
    }

    public String getNombre() {
        return nombre;
    }

    public double getSueldoBase() {
        return sueldoBase;
    }

    public int getHorasExtras() {
        return horasExtras;
    }

    public void setHorasExtras(int horasExtras) {
        this.horasExtras = horasExtras;
    }

    public double calcularPagoExtras() {
        return horasExtras * 20;
    }

    public double calcularSueldoTotal() {
        return sueldoBase + calcularPagoExtras();
    }

    public void mostrarDatos() {

        System.out.println("Codigo: " + codigo);
        System.out.println("Nombre: " + nombre);
        System.out.println("Sueldo base: " + sueldoBase);
        System.out.println("Horas extras: " + horasExtras);
        System.out.println("Sueldo total: " + calcularSueldoTotal());
    }
}

ARCHIVO: TestEmpleado.java

package ejercicio;

public class TestEmpleado {

    public static void main(String[] args) {

        Empleado e1 = new Empleado(1, "Carlos", 1500, 5);
        Empleado e2 = new Empleado(2, "Maria", 1800, 8);

        e1.mostrarDatos();
        e2.mostrarDatos();
    }
}
