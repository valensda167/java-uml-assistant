POO: modela las responsabilidades de cada clase. Encapsula el estado con private cuando corresponda. Usa constructores para iniciar los atributos. Separa calculos de mostrarDatos y la clase de prueba del modelo, si el enunciado lo permite.
Colecciones: usa List para secuencias, Set para valores unicos y Map para relacionar claves y valores. Incluye los imports y todas las clases propias que el codigo use.
UML: + publico, - privado, # protegido. La herencia representa es-un; una referencia a otra clase puede representar una asociacion. Distingue agregacion y composicion por propiedad y ciclo de vida. Deduce multiplicidades solo cuando los requisitos o el codigo las respalden.
Estilo NetBeans: usa PascalCase en clases, camelCase en miembros y nombres en espanol si el enunciado lo permite. Usa una clase modelo con atributos, constructor y metodos, y una clase TestNombre con main que crea instancias y las prueba. Mantiene el mismo package entre archivos relacionados.
UML desde Java: genera el diagrama desde las declaraciones del codigo compilado. Representa extends e implements segun lo declarado. Para un atributo que apunta a una clase del mismo ejercicio, representa una asociacion. Una lista o un array de esa clase admite 0..* elementos; para referencias simples conserva la multiplicidad sin especificar cuando el codigo no la establece.
